# Herbal Garden

A modern interactive platform for exploring medicinal herbs, AYUSH wellness systems, and guided healing journeys.

## Key Features

- Explore 15+ featured medicinal plants with detailed uses and properties
- Guided wellness tours for digestive health, immunity, and skin care
- Interactive quizzes on AYUSH systems and herbal knowledge
- 3D interactive plant model viewer
- Video tutorials featuring herb benefits and wellness practices
- Plant identification through image upload
- Herb encyclopedia with traditional knowledge
- Responsive design for mobile, tablet, and desktop

## Getting Started

**Requirements:** Node.js 16+ and npm

**Installation:**

```bash
npm install
```

**Start the application:**

```bash
npm run dev
```

Visit http://localhost:5173 in your browser.

**Build for deployment:**

```bash
npm run build
```

## Configuration

To enable plant identification via image upload, create a `.env` file with:

```
VITE_PLANT_ID_API_KEY=your_api_key
VITE_PIXABAY_API_KEY=your_api_key
```
